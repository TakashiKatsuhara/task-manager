☁ GitHub同期

データはあなたのプライベートリポジトリの tasks.json に保存されます。会社の休み設定も一緒に同期されます。 未設定の場合はこの端末内のみに保存されます。
この端末のブラウザ内（localStorage）にのみ保存されます。共用PCでは使用しないでください。
初回セットアップ手順（トークンの作り方）
  1. GitHubでプライベートリポジトリを作成（例: task-data）。中身は空でOK（tasks.jsonは自動作成されます）
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → task-data のみ選択
  4. Permissions → Repository permissions → Contents: Read and write
  5. 有効期限（最大1年）を設定して生成。表示されたトークンを上の欄に貼り付け
  6. スマホでも同じ値を入力すれば同期完了
